# Lorry Promo code

## Игрок
- `/start` — регистрация
- 🎟 промокоды `LORRY_...`
- 💰 заявка на голду (сумма + игровой ник)
- 👤 профиль и баланс

## Админ
- `+промо LORRY_КОД СУММА` — создать промокод (лимит активаций — `PROMO_LIMIT` в config.py, по умолчанию 5)
- 📊 мониторинг, 📨 заявки, ✅ одобрить / ❌ отклонить

## Запуск
1. `pip install -r requirements.txt`
2. `.env.example` → `.env`, вписать `TOKEN` и `ADMIN_IDS` (через запятую)
3. `python main.py`

Баланс — внутренняя запись бота, голду в игре админ выдаёт вручную.
